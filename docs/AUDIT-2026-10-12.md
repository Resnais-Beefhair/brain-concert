# Audit decisions — 12 October 2026

The supplied 17 issue drafts were checked against the actual source. Draft line
numbers and proposals were treated as review input, not as requirements to make
unrelated architectural or scientific changes.

1. **Formatting/lint: accepted.** Standalone formatting commit, blame-ignore list,
   Prettier, ESLint and EditorConfig. Formatter equivalence check passed and the
   minified application JS was byte-identical immediately after formatting. CSS
   hash changes also changed the bootstrap's asset references.
2. **CI/Dependabot: accepted.** Node 22, read-only permissions, SHA-pinned actions,
   checks plus browser job; weekly grouped updates. Scheduling is configured,
   not a claim that a future weekly PR has already run.
3. **State/modules: targeted implementation.** Central resettable model/view state,
   pure inputs, UI and inspector modules. Runtime GPU/audio/recording handles and
   lifecycle remain explicit in the orchestrator; replacing every field with an
   indiscriminate `Object.assign` would also reset user audio consent and running
   resources. No framework or blanket rewrite. Reset preserves language, volume,
   audio consent and play/pause, but resets the experiment and view.
4. **Community docs: accepted with lightweight conduct rules.** No invented private
   email or staffed enforcement promises. The security reporting link is enabled.
5. **Tests: accepted.** Loader integrity/HTTP failure cases, sensory rates, settings
   validation, event-log order, reset state; synthetic browser CI also covers actual
   startup, reset, sharing, localization, export and missing WebGPU. The full dataset
   remains a local release gate, not a CI download dependency.
6. **Errors: accepted.** Translated user messages; technical codes stay in diagnostics
   and an expandable detail. Hosted users are not told to run developer npm commands.
7. **Tags/releases: accepted.** Tag the original published commit as 2.5.1 and the new
   version as 2.6.0. Release packaging excludes dataset payloads and supplies setup
   instructions plus checksums. No GitHub Pages mirror: retain the existing HTTPS
   site and same-origin dataset/precompression, avoiding a second origin and CORS.
8. **Repo metadata: targeted.** Topics and private reporting enabled. Discussions
   stays off to avoid an unused second support channel. Social preview is not a
   prerequisite; the existing README image stays. No unrelated account settings.
9. **Issue/PR templates: accepted.** Reproduction environment, GPU and diagnostics,
   focused feature requests, and evidence checklist.
10. **Bundle split: accepted.** Three.js in its own chunk; no warning threshold raised.
    The small audio module stays synchronous because a new asynchronous audio
    activation path is not justified just to remove a build warning.
11. **HTML interpolation: accepted.** Static bundled UI and inspector markup;
    translations and neuron metadata use textContent. Numerical SVG loader paths
    remain generated locally, not from external data.
12. **Diagnostics: documented public read-only snapshots.** Existing fields/tests
    remain available in production; each access copies and freezes the error list.
13. **Downloader: accepted.** Stream both download and local verification; check
    length and SHA-256 before atomic rename and clean partial files on failure.
    Multiple mirrors/retries are not added without a maintained alternative mirror.
14. **Small usability fixes: accepted.** Translated language name, chronological
    ring log, engine-strict and Node 22 selection (latest patch, not frozen 22.12; current lint tooling requires 22.20+ (22.x) or 24.12+).
15. **Sampled light network: deferred.** This changes the graph and model behaviour,
    not just rendering quality. Do not silently weaken the whole-network artwork.
16. **Settings links: accepted.** Allowlisted hash values and string neuron IDs.
    Activity, audio consent and private data are not serialized. Invalid values are
    ignored; a missing neuron does not prevent startup.
17. **Randomized controls: separate research task.** Degree alone does not control
    signed weights, sensory populations or temporal/synthesis confounds. No quick
    graph shuffle is presented as biological validation. The README's limitation
    remains explicit; no claim of completed control-network evidence is made.
